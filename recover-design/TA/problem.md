# Project 3 — Recover the Design

来源：用户于 2026-10-21 提供的 PTA 题目截图，题号 8-1，20 分；作者陈越，浙江大学。以下为题意整理，不补写截图未显示的时间、内存限制或额外样例。

## 任务

花园是 n × m 的单位方格区域，各位置可能有度数为 k 的连接器 (connector)。恢复水平或竖直的围栏 (fence)，使每个连接器恰好连接 k 个方向。

围栏不能弯折；只能在连接器处形成转角；没有连接器的位置不能交叉。不要求所有连接器属于同一个连通分量 (connected component)。同一方向上的围栏遇到连接器后形成一段连接，若继续延伸则使用该连接器的另一方向。

## 输入

一组测试。首行为 n m，满足 1 < n, m ≤ 50。接下来 n 行，每行 m 个整数：0 表示无连接器，1 至 4 表示连接器的度数 (degree)。

## 输出

无解时只输出 `No Solution`。

有解时按行优先、每行从左到右，对每个非零位置输出：

```text
row col up down left right
```

坐标从 1 开始；四个方向的值为 0 或 1。数字用一个空格分隔，行首行尾无额外空格。有多个解时输出任意一个。

全零输入没有需要输出的连接器，按上述规则输出空内容。

```text
5 6
0 0 2 0 0 2
1 3 3 1 0 0
2 2 1 0 0 2
0 0 0 0 0 1
2 0 2 0 0 2
```
