# ADS LaTeX 项目报告模板

这是从课程原始模板中提炼出的可直接使用版本，保留了课程要求的报告结构，并整理了目录、二级标题、中文、代码、表格、定理和参考文献配置。

## 使用方法

1. 在 `main.tex` 的“只需修改这里”区域填写项目名称、小组编号和成员姓名。
2. 分别编辑 `sections/` 中的正文文件。
3. 将图片放进 `figures/`，代码放进 `code/`。
4. 在项目根目录运行：

   ```bash
   latexmk main.tex
   ```

   清理编译产物：

   ```bash
   latexmk -c
   ```

## 目录结构

```text
ADS/
├── main.tex                 # 总入口与封面信息
├── ads.bib                  # 参考文献数据库
├── latexmkrc                # 默认使用 XeLaTeX
├── sections/                # 正文章节
├── appendix/                # 附录
├── figures/                 # 图片
└── code/                    # 项目源代码
```

课程原模板注明这些只是最低要求，具体项目作业可能有额外要求；提交前请再次核对当次作业说明。
