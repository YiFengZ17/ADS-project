## 必须优先修正

### 1. 第 7 页 §3.2：复现说明应以提交包为准

正文要求 make、make self-test、make sanitizer 和 python3 scripts/analyze.py，但 TA/ 只有 PDF、README.md 和 code/main.cpp。TA/README.md 的直接编译方式可用，论文与 README 却给了不同入口。

建议：正文明确以 TA/ 为工作目录，给出直接编译、测试和运行命令；如果保留 make 与分析脚本，须将对应文件纳入正式打包流程并同步交付。不要让读者猜测哪些命令只能在开发仓库运行。建议提供从 CSV 到表格、图片的轻量分析脚本，但无需上传历史计时 CSV 或道路数据。

### 2. 第 10 页 §3.6：性能原因需要落到具体实现

当前用数组局部性与链式结构解释差距，方向合理，且已有“未测硬件事件”的限制语，但缺少三个直接来自代码的事实：

- fib_dijkstra 在每次查询开始为全图 n 个顶点构造 Node 数组，并初始化 dist、state；并非只为本次搜索实际发现的顶点分配节点。Binary 也初始化 dist，但对象初始化负担不同。
- consolidate 每次建立 roots 与 by_degree 临时 vector；pop 在有子节点时还建立 children vector。这些分配和遍历都在计时区间内。
- 三图 m/n 为 2.426–2.776，是稀疏图。若把这类图看作 m=Θ(n) 的图族，则二叉堆与 Fibonacci Dijkstra 的最坏上界都化为 O(n log n)。因此不能期待仅凭一般图上的更强上界就获得此处的速度优势。

建议直接补入这些事实，将“可能的性能来源”与“已测得的原因”明确区分。没有剖析数据时，不写“6 倍差距主要由某因素造成”。可另计入队、有效/过期出队、decrease-key、扫描边数、初始化耗时，帮助检验解释；这些是后续实验，不是现在已经完成的结果。

### 3. 第 3–4 页 §2.1：解析器声明与实现不完全一致

read_graph 没有统一检查字段提取是否成功，也没有记录是否已经读到唯一合法 header。额外测试确认：仅含注释的文件被接受为 0 顶点图，重复的 p sp 1 0 header 也被接受。缺失 header 的图之后传入查询生成逻辑会有进一步风险。

建议补上 header 存在且唯一、字段读取成功、m 非负、header 先于 arc 等检查，并补相应失败用例。若暂不修代码，应收窄正文的防错声明。这里是输入健壮性问题，不能据此断言合法 DIMACS 数据上的最短路结果错误。

### 4. 第 5 页 §2.4 与第 7 页 §3.2：区分逻辑状态和存储分配

正文的“one node for each discovered, unsettled vertex”适合描述活动堆中的节点，但物理 Node 数组实际覆盖全部顶点。建议补一句：节点存储每次按 n 预分配，仅发现且未确定的顶点处于活动堆中。

§3.1 明确允许重复抽样，但 §3.2 又写“1,000 distinct pairs”。建议把后者改为“1,000 sampled pairs”，避免暗示去重。

## 实验改进：有助于接近满分

1. 在同一查询集合上增加多轮计时，交替或随机安排两种实现顺序，记录预热与计时轮数。工作负载分位数不等于重复计时的测量不确定性；若增加误差棒，应说明它表示什么。
2. 把独立参照加入正式 self-test，例如小图 Floyd–Warshall，并用确定性堆操作序列覆盖合并、decrease-key 和级联切割。当前双方互相核对并非独立 oracle，论文对此已经诚实说明。本次额外检查通过不应被写成原作者在 10 月 16 日已完成的测试。
3. 补充关键注释：state=0/1/2 的含义、Node 指针为何稳定、根链快照与 detach 的关系、提升子节点的处理。现有每函数注释是优点，无需对简单赋值逐行注释，但复杂函数应拆开过密语句。

## 实际验证记录与边界

环境：WSL2 Linux 6.6.87.2-microsoft-standard-WSL2，Ubuntu GCC 13.3.0；这不是论文中的 Apple M4 环境。

在仓库根目录运行：

```bash
c++ -std=c++17 -O2 -Wall -Wextra -Wpedantic shortest-path-heaps/TA/code/main.cpp -o /tmp/ads-review-benchmark
/tmp/ads-review-benchmark --self-test
c++ -std=c++17 -g -O1 -fsanitize=address,undefined -fno-omit-frame-pointer shortest-path-heaps/TA/code/main.cpp -o /tmp/ads-review-san
/tmp/ads-review-san --self-test
```

两次均输出 `PASS: edge cases and 2000 random pairs`。提交源码与开发源码 cmp 一致。

额外临时测试程序 `/tmp/ads-review-extra.cpp` 使用 seed 20261017，生成 100 个 15 顶点的小图，交替使用 15/90 条随机边，允许自环、重边和零权；对每图全部 225 对端点，用 Floyd–Warshall 与两种 Dijkstra 比较，共 22,500 对查询，全部通过。该程序带 ASan/UBSan 运行；因把原 main 宏重命名后 include 产生“非 void 函数走到末尾”的警告，属于临时测试封装，原始提交按上述标准编译无该警告。额外程序同时确认了缺失/重复 header 被接受的问题。

本地没有 shortest-path-heaps/data/，未重跑 NY/BAY/COL 大路网实验，无法重新计算历史均值、分位数和 3,000 对距离一致性。表中三个均值比值与报告 6.54、6.22、6.31 的表述相符；这只是汇总数字的内部一致性，不是历史实测的独立复现。
