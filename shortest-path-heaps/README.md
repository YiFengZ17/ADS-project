# Project 2: Shortest Path Algorithm with Heaps

This project compares Dijkstra's algorithm with a lazy binary heap and a Fibonacci heap. Source code is `code/main.cpp`; the report source is `report/report.md`. `figures/` contains the report plot. `TA/` contains the named submission, and `Peer Review/` contains the anonymous submission. Local `data/` and `build/` are ignored by Git.

课程评分要求见 [Grading Policy and Rubric](grading-policy.md)：包含 20 分 Grading Policy、六项评分细则及各项扣分条件。后续代码、测试、报告及提交包审核应按此完整细则核对；`opinion/` 中的历史模拟评分不代表已按新补充的细则重新审核。

The three graph input links are listed in `report/report.md`; download `NY`, `BAY`, and `COL` from the 9th DIMACS distance graph collection. From this directory, run:

```sh
make
make self-test parser-test
make sanitizer
mkdir -p data
for x in NY BAY COL; do
  curl -L --fail "https://www.diag.uniroma1.it/challenge9/data/USA-road-d/USA-road-d.$x.gr.gz" -o "data/USA-road-d.$x.gr.gz"
  gzip -cd "data/USA-road-d.$x.gr.gz" > "data/USA-road-d.$x.gr"
  ./build/benchmark --validate "data/USA-road-d.$x.gr"
  ./build/benchmark "data/USA-road-d.$x.gr" 1000 20261016 --repeat 3 > "data/results-$x.csv"
done
python3 scripts/analyze.py
python3 scripts/build_report.py --compile
python3 scripts/build_report.py --compile --anonymous
python3 scripts/package.py
```

The benchmark requires a C++17 compiler. `make sanitizer` requires Clang or GCC sanitizers. Plotting needs Python 3 and matplotlib. PDF building needs `markdown-it-py`, XeLaTeX, and the fonts specified by `scripts/report-style.tex`. The CSVs, summary, and percentile table stay in `data/`; the plot goes in `figures/`; the named and anonymous PDFs are built in `build/`. `scripts/package.py` copies only the checked PDF, executable source in `code/`, and README into each submission folder and verifies anonymity. Makefile, test/analysis scripts and generated outputs stay in the development directory; unexpected submission entries cause packaging to fail. Run it only after reviewing the PDFs. The benchmark exits with an error if paired distances differ. The 1,000 source-target pairs are generated by the fixed seed, and the CSV records them explicitly. `--repeat 3` times every query three times and keeps the median, so one unlucky scheduling or paging event does not dominate a single query. The attribution mode `./build/benchmark --attribute data/USA-road-d.NY.gr 1000 --repeat 3` splits each query into initialization and search, counts the work each queue does, and reports an indexed binary heap as a third reference point.
